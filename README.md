# Awesome Site Migration & Canonical Architecture

Курируемый справочник лучших практик, инженерных паттернов и инструментов для бесшовной миграции крупных веб-ресурсов, интернет-магазинов и порталов без потери органического трафика и позиций в поисковых системах.

Разработано и поддерживается студией [Каноникалисты](https://kanonikalisty.ru/).

---

## Архитектура 4 станций безопасного переезда

1. **Станция 1: Карта URL**
   - Полная инвентаризация структуры существующего сайта.
   - Выгрузка логов обращений Googlebot и YandexBot за последние 12 месяцев.
   - Построение поадресной матрицы соответствия 1-к-1.
   - Устранение потенциальных цепочек редиректов (Target: 0 Chains).

2. **Станция 2: Тестовый стенд (Staging)**
   - Настройка изоляции через Basic Authentication.
   - Проверка отдачи заголовков HTTP 301, 404, 200 через автоматизированные краулеры.
   - Валидация канонических тегов `rel="canonical"` и `hreflang`.
   - Сверка мета-тегов (`title`, `description`, `h1`).

3. **Станция 3: День переезда (Release Day)**
   - Переключение A-записей DNS (с предварительно заниженным TTL).
   - Загрузка `map`-конфигураций в Nginx.
   - Проверка снятия блокирующих директив в `robots.txt`.
   - Отправка обновленных карт сайта `sitemap.xml` в поисковые консоли.

4. **Станция 4: Наблюдение и стабилизация (30 дней)**
   - Потоковый парсинг логов web-сервера.
   - Мгновенное купирование всплесков 404 ошибок.
   - Отслеживание динамики склейки зеркал и индексации.
